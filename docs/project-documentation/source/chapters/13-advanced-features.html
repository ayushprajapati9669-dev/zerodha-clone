Chapter 13 — Advanced Ecosystem Features

13.1 Multi-Watchlist System (watchlistsController.js)

Similar to Zerodha Kite's multi-watchlist tab navigation (Watchlist 1 through 7), the platform allows traders to organize equities into distinct custom lists:

  • Up to 7 watchlists per user, each holding up to 50 stock symbols.
  • Custom watchlist naming (e.g. "Banking", "IT Sector", "High Beta").
  • Symbol re-ordering via drag-and-drop or sequential array storage.
  • Fast hovering quick-action buttons for instantaneous Buy/Sell, market depth, and chart expansion.

13.2 Price Target Alerts (priceAlertController.js)

Traders can set automated alerts for any stock based on condition triggers:

  • Conditions: GREATER_THAN_OR_EQUAL (Price >= Target) or LESS_THAN_OR_EQUAL (Price <= Target).
  • Evaluation Engine (evaluateAlerts): Whenever TrueData emits a live price tick, evaluateAlerts(symbol, ltp) inspects active alerts for that symbol.
  • Notification Trigger: When a condition triggers, the alert is marked status: 'triggered', a high-priority in-app notification is recorded, and an event is dispatched over Socket.IO to the user's browser.

13.3 In-App Notifications & Preference Control

The notification subsystem (NotificationModel.js) delivers real-time and persistent alerts categorized by priority (low, normal, high):

  • Event Categories: Order filled, limit order triggered, price alert hit, fund deposit/withdrawal confirmed, tournament status change.
  • Granular User Preferences (NotificationPreferenceModel.js): Users can toggle individual alert types on or off (e.g., disable deposit alerts while keeping limit order fill alerts enabled).
  • Unread Tracking: Distinct read/unread timestamps and a bulk "Mark All as Read" endpoint (POST /api/notifications/read-all).

13.4 Portfolio Analytics & Performance Metrics (portfolioAnalyticsService.js)

Provides data-driven feedback on user trading performance over time:

  • Asset Allocation: Sector and asset distribution breakdown (Large Cap, Mid Cap, Cash Reserve) visualized via Recharts pie charts.
  • Profit Factor: Total Gross Profits / Total Gross Losses.
  • Win-Loss Ratio: Profitable Closed Trades / Total Closed Trades * 100.
  • Historical Equity Curve: Daily portfolio equity snapshots captured via PortfolioSnapshotModel.js to chart historical account growth.

13.5 Risk Guard: Quantitative Risk Management (riskService.js)

To prevent catastrophic emotional drawdowns (tilt trading), the platform implements an active Risk Guard system:

  • Daily Loss Limit: Maximum loss permitted in a single trading day (e.g. ₹5,000). If hit, order placement triggers a warning or temporary restriction.
  • Maximum Position Size Cap: Restricts the maximum capital allowed in any single trade (e.g. max 20% of total portfolio).
  • Leverage Caps: Configurable maximum leverage allowed for intraday MIS positions.

13.6 Trading Journal (journalService.js)

Professional trading requires reflective review of setups, thesis, and emotional discipline:

  • Rich Notes & Setup Tags: Traders record technical rationale (Breakout, Pullback, Mean Reversion, Gap Fill).
  • Emotional Tags: Traders log emotional states (FOMO, Revenge Trade, Patient, Confident, Hesitant) to identify psychological patterns correlating with losses.
  • Trade Linking: Journal entries can be directly linked to executed order IDs to pair qualitative analysis with objective execution data.

13.7 Strategy Backtesting Engine (backtestEngine.js)

A quantitative historical simulation engine allowing traders to validate technical rules before risking capital:

  • SMA Crossover Strategy (smaCrossover.js): Simulates Fast Simple Moving Average (e.g. 9-period SMA) crossing Slow Simple Moving Average (e.g. 21-period SMA).
  • Signal Generation: Fast SMA crosses above Slow SMA -> BUY Signal. Fast SMA crosses below Slow SMA -> SELL Signal.
  • Simulation Performance Report: Generates Net Return %, Maximum Drawdown %, Win Rate %, Total Trades Executed, and Sharpe Ratio stored in BacktestHistoryModel.js.
