Chapter 9 — Holdings, Positions & P&L Calculations

9.1 CNC Delivery Holdings vs. MIS Intraday Positions

Following Indian market structure, the platform distinguishes between two trading products:

Dimension Cash 'N Carry (CNC) — Holdings Margin Intraday Square-off (MIS) — Positions
Investment Horizon Multi-day to multi-year long-term investment. Single trading session (closed before 3:15 PM IST).
Leverage Allowed 1x (No leverage: 100% upfront cash required). 5x intraday leverage supported.
Short Selling Not permitted (must own shares before selling). Permitted (sell high, buy back lower before close).
Storage Collection holdings collection (HoldingsModel). positions collection (PositionsModel).

9.2 Volume-Weighted Average Purchase Price Formula

When a trader purchases additional shares of an already owned stock at a different market price, the new cost basis is calculated using the Volume-Weighted Average Price formula: 

New Average Price = ( (Existing Qty * Existing Avg Price) + (New Qty * Purchase Price) ) / ( Existing Qty + New Qty )

Worked Example:

  • Trader currently owns 10 shares of TCS with an average cost of ₹3,200 (Invested = ₹32,000).
  • Trader buys 5 additional shares of TCS at the current market price of ₹3,500 (New Outlay = ₹17,500).

New Total Quantity = 10 + 5 = 15 shares

New Total Invested = ₹32,000 + ₹17,500 = ₹49,500

New Average Price = ₹49,500 / 15 = ₹3,300 per share

9.3 Real-Time P&L Equations

The frontend Kite dashboard dynamically calculates real-time profit and loss metrics across every holding and for the aggregate portfolio:

1. Individual Holding Total P&L

Holding Invested Value = Quantity * Average Price
Holding Current Value  = Quantity * Current Market Price (LTP)
Total Profit / Loss    = Holding Current Value - Holding Invested Value
Percentage Return (%)  = ( Total Profit / Loss / Holding Invested Value ) * 100

2. Individual Holding Day P&L

Measures the profit or loss generated exclusively within the current trading session: 

Day Profit / Loss   = Quantity * ( Current Market Price - Previous Day Close Price )
Day Return (%)      = ( ( Current Market Price - Previous Close ) / Previous Close ) * 100

3. Portfolio Aggregate Metrics (PortfolioSummary.jsx)

  • Total Portfolio Invested = Sum of all (Quantity * Average Price)
  • Total Portfolio Current = Sum of all (Quantity * LTP)
  • Net Unrealized P&L = Total Portfolio Current - Total Portfolio Invested
  • Net Day P&L = Sum of all (Quantity * (LTP - Previous Close))

9.4 Sell Inventory Reservation (Anti-Double-Spend)

To prevent traders from placing multiple sell orders exceeding their actual owned shares:

  1. When a trader places a Limit Sell for 4 shares out of 10 owned shares: 
    Holding.updateOne({ userId, symbol }, {
  $inc: { quantity: -4, reservedQuantity: +4 }
});
  2. The available quantity immediately drops to 6 shares. If the user attempts to place another sell order for 7 shares, the system validates against quantity (6) and rejects the request.
  3. When the limit order executes, reservedQuantity is decremented by 4.
  4. If the user cancels the order, quantity is incremented by 4 and reservedQuantity is decremented by 4.
