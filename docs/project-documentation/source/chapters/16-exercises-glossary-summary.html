16.1 Hands-On Coding Exercises

These exercises reinforce your understanding of core financial engineering and full-stack patterns implemented in this codebase:

Exercise 1: Implement a Stop-Loss Market (SL-M) Order Type

Goal: Add support for Stop-Loss Market (SL-M) orders that remain pending until a trigger price is hit, at which point they execute immediately as market orders.

  • Hint: Add 'SL-M' to orderType enum in OrdersModel.js and add a triggerPrice field.
  • Hint: In createOrderServices.js, reserve funds or shares based on trigger price. In checkPendingLimitOrders.js, evaluate: For Buy SL-M, trigger when LTP >= triggerPrice; For Sell SL-M, trigger when LTP <= triggerPrice.
  • Learning Outcome: Master conditional order triggers and multi-state order lifecycles.

Exercise 2: Implement Real-Time Margin Call Notification

Goal: If a user's total unrealized intraday loss in MIS positions exceeds 80% of their available margin, dispatch an urgent high-priority notification via Socket.IO.

  • Hint: Create a helper in riskService.js that sums (CurrentPrice - AvgPrice) * Qty across open positions whenever TrueData ticks arrive.
  • Hint: If unrealizedLoss > 0.8 * availableBalance, emit margin-warning over Socket.IO to room user:{userId}.
  • Learning Outcome: Understand risk management thresholds and proactive event-driven alerts.

Exercise 3: Add Trailing Stop Loss to Strategy Backtesting

Goal: Enhance backtestEngine.js to support dynamic trailing stop-loss percentages (e.g. 2% below highest peak price achieved since position entry).

  • Hint: Maintain a highestHigh variable updated on each candle while in an active position. Calculate stopPrice = highestHigh * (1 - trailPercent). Exit if candle low crosses below stopPrice.
  • Learning Outcome: Experience dynamic risk-reward modeling in quantitative trading simulations.

16.2 Comprehensive Financial & Tech Glossary

TermDefinition & Project Context
CNC (Cash 'N Carry) Equity delivery product type where shares are purchased with 100% upfront capital and held indefinitely in the user's holdings portfolio.
MIS (Margin Intraday Square-off) Intraday leveraged trading product where positions must be closed before market session close. Supported in the positions collection.
LTP (Last Traded Price) The latest price at which a stock transaction occurred on the exchange. Broadcast by TrueData WebSocket ticks.
Limit Order An order to buy or sell a stock at a specified price or better. Requires capital or stock reservation in the ledger while pending.
Touchline Tick Live top-of-book market feed data containing symbol, LTP, volume, open, high, low, and previous close.
VWAP / Average Price Volume-Weighted Average Price formula used to compute cost basis across multiple purchases of the same stock.
Three-Tier Ledger The financial model separating liquid capital (availableBalance), deployed capital (usedBalance), and locked commitments (reservedBalance).
Token Versioning A database-backed session invalidation pattern enabling immediate revocation of all active JWTs when logging out of other devices.
Socket.IO Room An isolated channel for targeted message broadcasts (e.g. user:{userId} for personal notifications and tournament:{id} for leaderboards).
Context Injection The technique of querying a user's holdings, positions, and orders on-the-fly and injecting them into the Gemini AI system prompt for personalized responses.
