Chapter 10 — Market Data & TrueData Integration

10.1 Market Data Ingestion Overview

Real-time market price feeds are ingested via TrueData, an authorized data vendor for the National Stock Exchange of India (NSE) and Bombay Stock Exchange (BSE). The platform consumes real-time tick streaming over persistent WebSocket connections and historical candle records via HTTP REST endpoints.

10.2 TrueData WebSocket Client (trueDataService.js)

The native WebSocket client manages authentication, subscription, and parsing of binary/JSON touchline ticks: 

const url = `wss://push.truedata.in:${port}?user=${username}&password=${password}`;
wsConnection = new WebSocket(url);

wsConnection.on('message', (data) => {
  const jsonObj = JSON.parse(data);
  if (jsonObj.success && jsonObj.message === 'TrueData Real Time Data Service') {
    // Authenticated! Subscribe to 14 core NSE blue-chips:
    wsConnection.send(JSON.stringify({
      method: 'addsymbol',
      symbols: ['RELIANCE', 'TCS', 'INFY', 'HDFCBANK', 'ICICIBANK', 'SBIN', 'ITC', ...]
    }));
  } else if (jsonObj.symbollist) {
    // Process touchline tick records
    jsonObj.symbollist.forEach(processStockTick);
  }
});

Symbol Normalization:

To prevent mismatch bugs between exchanges and user inputs, all symbols pass through normalizeSymbol(symbol): 

const normalizeSymbol = (symbol) =>
  String(symbol || "")
    .trim()
    .toUpperCase()
    .replace(/^NSE:/i, "")
    .replace(/^BSE:/i, "");

10.4 Offline & Development Resilient Fallback Cache

In development environments, sandboxes, or during off-market hours (weekends and evenings), external WebSocket push feeds may be unavailable. If unhandled, empty price maps cause trading calculations, order evaluation, and watchlist rendering to crash.

Zerodha Clone solves this by initializing latestTrueDataPrices with a high-fidelity static baseline cache covering all 14 supported symbols. When live TrueData feeds connect, the live ticks overwrite the baseline cache in real time. If live connectivity is severed, the system continues operating smoothly.

10.5 Historical Price Data Service (trueDataHistoricalService.js)

Historical OHLCV candle records are fetched for rendering interactive price charts in StockChartPopup.jsx:

  • Endpoint: GET /api/market/prices/:symbol/historical?range=1M
  • Supported Ranges: 1M (1 Month, 15-min candles), 1Y (1 Year, daily candles), 5Y (5 Years, weekly candles), MAX.
  • Token Caching: Historical REST authentication tokens are acquired from https://auth.truedata.in/token and cached in memory with an expiration timestamp to prevent unnecessary re-authentication overhead.
